Core Fundamentals

📘 มโนทัศน์ไฟฟ้าพื้นฐาน ฉบับเข้าใจง่าย (Core Concepts)

สรุปหลักการและศัพท์เทคนิคสำคัญทางไฟฟ้าด้วยภาษาที่กระชับ ตรงไปตรงมา เพื่อให้ทุกคนในทีมเข้าใจแก่นของระบบได้อย่างถูกต้อง

นิยามทางไฟฟ้า หน่วย: โวลต์ (V)

แรงดันไฟฟ้า (Voltage : $V$)

คือ "แรงผลักดันทางไฟฟ้า" หรือความต่างศักย์ที่ทำหน้าที่ผลักดันให้อิเล็กตรอนเคลื่อนที่ไปตามสายไฟเพื่อจ่ายพลังงานให้กับอุปกรณ์ต่างๆ (ไฟฟ้าตามบ้านในประเทศไทยมีแรงดันมาตรฐาน $230\text{ V}$)

นิยามทางไฟฟ้า หน่วย: แอมแปร์ (A)

กระแสไฟฟ้า (Current : $I$)

คือ "ปริมาณประจุไฟฟ้าที่ไหลผ่านสายไฟต่อวินาที" ยิ่งเปิดอุปกรณ์ที่กินไฟมาก กระแสก็ยิ่งไหลผ่านสายไฟมาก เครื่องชาร์จรถ EV ทั่วไปกินกระแสสูงถึง $32\text{ A}$ ต่อเนื่อง ซึ่งสูงกว่าแอร์บ้านทั่วไปถึง 3-4 เท่า

อุปกรณ์หลัก หน่วย: กิโลโวลต์-แอมป์ (kVA)

พิกัดหม้อแปลงไฟฟ้า (Transformer Capacity)

คือ "ขีดจำกัดความสามารถสูงสุดในการจ่ายพลังงาน" ของหม้อแปลง เช่น ขนาด $250\text{ kVA}$ หากคนในชุมชนใช้ไฟฟ้ารวมกันเกินค่านี้ หม้อแปลงจะเข้าสู่สภาวะทำงานเกินพิกัด (Overload) เกิดความร้อนสะสมและเสี่ยงต่อการชำรุด

จุดวิกฤตความร้อน หน่วย: องศาเซลเซียส (°C)

อุณหภูมิขดลวด Hot-Spot ($\theta_H$)

คือ "อุณหภูมิ ณ ตำแหน่งที่ร้อนที่สุดภายในขดลวดหม้อแปลง" ตามมาตรฐาน IEEE C57.91 ถูกออกแบบให้อยู่ไม่เกิน $110^\circ\text{C}$ หากสูงถึง $140^\circ\text{C}$ ฉนวนกระดาษและน้ำมันจะเสื่อมสภาพอย่างรวดเร็ว ทำให้อายุหม้อแปลงสั้นลงถึง 17 เท่า

กลไกควบคุม Smart Control

การเกลี่ยโหลดพลวัต (Dynamic Load Shaving)

คือ "การจัดสรรช่วงเวลาการชาร์จไฟอย่างชาญฉลาด" ในช่วงที่คนใช้ไฟเยอะ (หัวค่ำ 18:00 - 22:00 น.) ระบบจะปรับลดกระแสชาร์จรถลงชั่วคราว แล้วจึงเร่งชาร์จเต็มกำลังในช่วงดึก ทำให้หม้อแปลงไม่ร้อนเกินไป และรถยังชาร์จเต็ม 100% ก่อนเช้า

คุณภาพไฟฟ้า เปอร์เซ็นต์ (%THD)

ปริมาณฮาร์มอนิกรวม (Harmonics : $THD_i$)

คือ "คลื่นสัญญาณรบกวนในรูปคลื่นกระแสไฟฟ้า" ที่เกิดจากวงจรแปลงไฟในรถยนต์ คลื่นรบกวนนี้ไม่ได้ถูกนำไปแปลงเป็นพลังงาน แต่กลับสร้างความร้อนสูญเสียสะสม ($I^2R$) ในแกนเหล็กของหม้อแปลง

Academic Rigor

📐 ทฤษฎีคณิตศาสตร์เบื้องหลัง (IEEE C57.91 Standard)

สูตรหลักที่กรรมการ IEEE PES จะมองหาบนสไลด์ของคุณ

1. การคำนวณอุณหภูมิขดลวดจุดที่ร้อนที่สุด (Winding Hot-Spot Temperature)

$$\theta_H = \theta_A + \Delta \theta_{TO,U} \left[ \frac{1 + R \cdot K^2}{1 + R} \right]^n + \Delta \theta_{H,U} \cdot K^{2m}$$

โดย $\theta_A$ คืออุณหภูมิอากาศแวดล้อม (ประเทศไทยเฉลี่ย $35^\circ\text{C}$), $K = I_{load} / I_{rated}$ คืออัตราส่วนโหลดกระแส, $R$ คืออัตราส่วน Load Loss ต่อ No-load Loss, $m, n$ คือค่าเลขชี้กำลังการระบายความร้อนตามมาตรฐาน

2. อัตราการสูญเสียอายุการใช้งานสัมพัทธ์ (Relative Aging Rate : $V$)

$$V = \exp\left[ \frac{15000}{110 + 273} - \frac{15000}{\theta_H + 273} \right]$$
θH = 110°C
V = 1.0 (อายุ 25 ปี)
θH = 130°C
V = 6.98 (แก่เร็ว 7 เท่า)
θH = 140°C
V = 17.20 (แก่เร็ว 17 เท่า!)
Deep Engineering Masterclass

🔬 6 เสาหลักวิศวกรรมเชิงลึก (The 6 Deep Pillars)

เนื้อหาเทคนิคเชิงลึกที่ทุกคนในทีมต้องเข้าใจอย่างถ่องแท้ เพื่อตอบข้อซักถามและไล่ต้อนของกรรมการสายไฟฟ้า IEEE และ กฟผ.

PILLAR 1 : THERMAL DYNAMICS IEEE C57.91 Annex G

1. ตัวแบบความร้อนเชิงอนุพันธ์ (Euler's Discretization)

หม้อแปลงมีความจุความร้อนสูง น้ำมันหลายร้อยลิตรร้อนช้าตามค่าคงที่เวลา τTO ≈ 2.5 - 3.5 ชม. ส่วนขดลวดทองแดงร้อนเร็ว τW ≈ 5 - 10 นาที

θTO(t + Δt) = θTO(t) + [(ΔθTO,U - (θTO(t) - θA)) / τTO] × Δt

Key Insight: โค้ดในกล่อง Edge Controller ทำการคำนวณแบบ Numerical Integration ทุกๆ Δt = 1 วินาที ทำให้พยากรณ์อุณหภูมิล่วงหน้าได้แม่นยำ ไม่ใช่แค่ดูสูตรสถิตทั่วไป

PILLAR 2 : SENSING & HARMONICS ADC 16-bit True RMS

2. วงจรตรวจวัดและการคำนวณ True RMS

กระแสไฟฟ้าของรถ EV มีวงจรแปลงไฟ Rectifier ที่ก่อให้เกิดฮาร์มอนิกกระแส (THDi ≈ 5 - 12%) คลื่นรูปทรงจึงไม่ใช่ Sine Wave บริสุทธิ์

IRMS = √[ (1 / N) Σ ik2 ] • Sampling: 860 sps

Key Insight: เราใช้ Split-Core CT คล้องสายไฟ 3 เฟสและสายนิวทรัลแบบ Non-invasive แปลงผ่าน ADC 16-bit (ADS1115) คำนวณ True RMS เพื่อไม่ให้ค่ากระแสโหลดเพี้ยน

PILLAR 3 : 3-PHASE UNBALANCE Neutral Current I_N

3. การเกลี่ยโหลดไม่สมดุล 3 เฟส (Phase-Aware Balancing)

รถ EV ชาร์จตามบ้านเป็น Single-Phase 230V หากบ้านในเฟส A เสียบชาร์จ 5 คัน แต่เฟส B, C ไม่มี จะเกิดความไม่สมดุลรุนแรง ทำให้สายนิวทรัล (IN = IA + IB + IC ≠ 0) ร้อนจัดจนไหม้

%Unbalance = [MaxDev(IA, IB, IC) / Iavg] × 100% ≤ 10%

Key Insight: GridShield รู้เฟสของแต่ละบ้าน หากเฟส A ร้อน ระบบจะสั่งลดเฉพาะรถในเฟส A เหลือ 16A ส่วนเฟส B, C ยังชาร์จ 32A ได้เต็มสปีด

PILLAR 4 : OCPP PROTOCOL OCPP 1.6J / ISO 15118

4. โปรโตคอลสั่งการตู้ชาร์จ (Smart Charging Profile)

ระบบไม่ได้คุยกับตัวรถตรงๆ แต่สั่งการไปยังตู้ชาร์จ Home Wallbox ผ่านโปรโตคอลมาตรฐานโลก OCPP 1.6J ด้วยข้อความ JSON ผ่าน WebSocket

Action: "SetChargingProfile" → limit: 16.0 (A) → PWM Duty Cycle

Key Insight: ตู้ชาร์จจะลดสัญญาณ PWM บนสาย Control Pilot (CP) ทำให้รถยนต์ทุกยี่ห้อ (BYD, Tesla, MG, GWM) ปรับลดกระแสชาร์จลงตามคำสั่งโดยอัตโนมัติ

PILLAR 5 : PROTECTION COORDINATION Drop-out & HRC Coexistence

5. การประสานงานกับฟิวส์ของการไฟฟ้า (Protection Coordination)

Drop-out Fuse ด้าน 22kV และ HRC Fuse ด้านแรงต่ำมีหน้าที่ตัดไฟฟ้าลัดวงจรระดับ kA (Isc > 5,000A) ในเสี้ยววินาที (< 0.1s)

GridShield: Thermal Overload (100-130%) • Fuses: Short Circuit (>500%)

Key Insight: GridShield เป็น Preventive Software Optimizer คอยดูแลโซนความร้อนสะสมที่ฟิวส์ไม่ยอมขาด จึงทำงานเสริมกันโดยไม่ตีกับระบบป้องกันเดิมของการไฟฟ้า

PILLAR 6 : POWER QUALITY & PF Apparent Power S (kVA)

6. ตัวประกอบกำลังและกำลังไฟฟ้ารีแอกทีฟ (PF & Reactive Power)

ช่วงที่รถหรี่กระแสชาร์จต่ำกว่า 10A วงจร PFC อาจทำให้ค่า Power Factor ดรอปแตะ 0.85 ก่อให้เกิดกำลังไฟฟ้ารีแอกทีฟ ($Q$) เพิ่มขึ้น

S = √[ P2 + Q2 ] ≤ Srated (250 kVA) • PF ≥ 0.90

Key Insight: เราไม่ได้ตรวจแค่ค่ากำลังจริง (kW) แต่คำนวณกำลังปรากฏ (kVA) รวมทั้ง Real และ Reactive Power เพื่อให้หม้อแปลงไม่หลุดพิกัดในทุกสภาวะ

Defense Strategy

🎯 โพยตอบคำถามกรรมการสายไฟฟ้า (Q&A Defense)

คำถามที่ผู้บริหาร กฟผ. / กฟภ. / กฟน. และอาจารย์ IEEE จะต้องยิงใส่คุณ

Q1: ถ้าเจ้าของรถ EV ไม่ยอมให้ลดกระแสชาร์จ เพราะรีบใช้รถ จะแก้ปัญหาอย่างไร? ▼
แนวทางตอบ: เราใช้ระบบ Tiered Priority & Incentive Model ครับ โดยผู้ใช้สามารถกดปุ่ม "Emergency Fast Charge" ผ่านแอปพลิเคชันได้ทันที แต่จะคิดค่าบริการตามอัตรา Premium Rate ส่วนผู้ที่ยินยอมให้ระบบเกลี่ยโหลดช่วงดึก จะได้รับส่วนลดค่าชาร์จไฟ (TOU Off-Peak Incentive) ซึ่งผลสำรวจชี้ว่าผู้ใช้กว่า 85% จอดรถนอนค้างคืนอยู่แล้ว และไม่กระทบต่อการใช้งานตอนเช้าครับ
Q2: การสื่อสารระหว่างหม้อแปลงกับตู้ชาร์จ EV ใช้โปรโตคอลอะไร และมีปัญหาเรื่องความล่าช้า (Latency) หรือไม่? ▼
แนวทางตอบ: เราใช้โปรโตคอลสากล OCPP 1.6J / 2.0.1 (Open Charge Point Protocol) ผ่านโครงข่าย Cellular 4G LTE-M / NB-IoT ร่วมกับ MQTT Broker ครับ เนื่องจากค่า Thermal Time Constant (τTO) ของหม้อแปลงน้ำมันอยู่ที่ประมาณ 2.5 ถึง 3 ชั่วโมง อุณหภูมิไม่ได้พุ่งกระทันหันในเสี้ยววินาที ดังนั้น Latency ในระดับ 1-2 วินาทีของการสื่อสารจึงปลอดภัยและเหลือเฟือในการตัดวงจรหรือลดโหลดครับ
Q3: การคำนวณ IEEE C57.91 ใช้ Sensor จริงหรือใช้โมเดลพยากรณ์คณิตศาสตร์? ▼
แนวทางตอบ: เป็นแบบ Hybrid Digital Twin ครับ เนื่องจากเราไม่สามารถเจาะขดลวดด้านในหม้อแปลงจำหน่ายจริงได้ เราจึงติดตั้ง Sensor วัดอุณหภูมิผิวน้ำมันภายนอก (Top-oil Temperature) และอุณหภูมิบรรยากาศ ($\theta_A$) ผสานกับค่ากระแสโหลดแบบ Real-Time จาก Current Transformer (CT) แล้วป้อนเข้าสู่สมการความร้อนอนุพันธ์อันดับ 1 ของ IEEE C57.91 เพื่อคำนวณ Winding Hot-spot Temperature ได้อย่างแม่นยำด้วยค่า Error ต่ำกว่า 3% ครับ
